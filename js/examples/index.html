flowfields examples

p5.js sketches that use flowfields.js. Each one is a single HTML file: save it anywhere and open it in a browser.

  • flow Lines through a sum of a rotation, an expansion and noise, with Gaussian weights.
  • colors Lines colored from an image with MatrixColorField.
  • regions FieldMax splits the plane into regions with sharp borders.
  • select FieldSelect makes one long line switch between rotations.
  • vortices Particles drift through four moving vortices and glow where their paths meet.
  • quantize quantizeVector turns circles into polygons.
